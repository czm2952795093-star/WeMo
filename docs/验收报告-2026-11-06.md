## 尚未通过的 AI 项目

衣物识别、AI 商品图重建、AI 试穿实际请求均未通过。百炼返回 401 invalid_api_key，方舟返回 401 AuthenticationError；进一步检查确认本地模型密钥仍为示例占位文字，并非已配置的真实密钥。

需要配置有效模型密钥、确认目标模型权限及剩余额度后重新验收。这些检查不能以首页可访问、接口返回规则兜底结果或填写了环境变量字段代替。

独立的阿里云视觉智能抠图路径还依赖 ALIBABA_CLOUD_ACCESS_KEY_ID / ALIBABA_CLOUD_ACCESS_KEY_SECRET；该路径未完成验收。ComfyUI 替代路径也需要可用服务地址。

## 本次修复

1. 避免将 Windows 或较新 Ubuntu 系统编译的 SQLite 原生库用于 Debian 11 云端运行时。
2. 使用完整 standalone 产物，实体化外部链接，防止忽略规则过滤 Next.js 依赖。
3. 在受保护请求响应前等待 SQLite 快照上传，降低实例归零后后台计时器不执行的风险。
4. 调整最大实例数为 1，补齐网关 PATCH 方法。

本报告覆盖上述 HTTP 与存储闭环，不代表所有界面交互、真实人体试穿质量或高并发场景已验收。
